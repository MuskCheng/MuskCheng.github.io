# 关于心理学

心理学是一门探索性科学，所以它是科学，而不是宗教信仰。

心理学以一种科学的态度在探索着人类的精神世界，而人，恰恰是这世上最难读懂的生物，有着复杂的感情，有着复杂的关系。有时候，你可能自以为认识了他（她），但是他（她）的一个行为就足矣改变你的这种想法。

# 关于爱情与婚姻

到底什么是爱情？好像没有人能给出真正适合的答案。

爱情之初是两人相见之后的怦然心动，是趣味相投之后的甜言蜜语，是缠绵，是激情退却，是相濡以沫？

好像并不是吧？

一系列的碰撞和激情冲昏了头脑，理智在爱情面前似乎一文不值，四目相望之中，对方竟是如此的完美无暇，就是自己心中所想，梦中所见；但当渐渐熟悉之后，来自于两个不同“世界”的人应该如何相处呢？（不同的人生观，不同的价值观，不同的世界观，当然，也有可能存在部分一只，但毕竟概率很小。）是一言不合就唾液横飞？是默默忍受压抑情感？这好像都不合适吧？

这是来自于两个不同“世界”的自我相互碰撞，化解的唯一方式就是开放、接纳，而不是对抗，更不是忍让。对抗和忍让只会慢慢的摧毁一个人的内心，进而抑郁，最终崩溃。无法敞开的内心，最终只会走向极端。

# 如何打破“自我”的界限？

每个人都在自己的意识中为自己树立了边界，这是一种自我保护的方式，这个边界以内就是自我，而边界以外就是“世界”，如何让一个人开放自己的界限呢？我的理解只有一种方式——信任！完全的信任会让人放松自我的界限，去接纳来自另一个世界的自我，去接纳她（他）的不完美，去熟悉她（他）的优点，只有这样，才能共同携手，共同前进，共同进步。爱情，理应是这样。

爱情，是一种无声的表达！爱情，不是一个人的事情。

# 关于爱

爱，是人类最伟大的情感。

这里引用一句原文，感觉十分贴切：“真正的爱，需要投入和奉献，需要付出全部的智慧和力量。要使爱的对象得到成长，就必须付出足够多的努力，不然爱的愿望就会落空。唯有真正的投入和奉献，才是实现爱的有效方式。”

爱是一种真情的流露。爱一个人，你会无以复加的把你的真情付诸其身，真爱是不求回报的。但，爱会让人成长，这是对你付出的回报。付出了真爱让对方感受到，被爱的人会感到幸福，付出的人会得到满足，这是一种心灵的告慰，是一举两得的事情。

爱所有人，叫做博爱！这是一种精神，普通人很难拥有。

但到底什么是爱？在我看来，爱是包容，是宽宏，是希望！是无所畏惧，是勇往直前！爱是相互扶持，爱的路上也许会很孤单，需要很强大的忍耐力，需要强大的内心。

但爱的路途上有无数的人和你一样，在负重前行，要相信，终有一天，阳光会出现。

不同于爱情，爱，可能是一个人的事情。

# 关于人生

这些年的经历有过辛酸，有过孤独，有过绝望，但好在内心还残留的那一丝希望，支撑着走过了这一段又一段的坎坷与艰辛。

活着，本就不是一件容易的事儿。心存宽宏，心存感恩，走到哪里都不会感到孤独。
