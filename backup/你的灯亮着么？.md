# 关于作者

本书作者是IT界的知名人士，但不要畏惧，这是一本方法论的书籍，也是一本值得你思考的书籍，适合于各行各业的人阅读，老少皆宜。

# 关于内容

无论是生活、工作还是学习中，都可能会被各种各样的问题所困扰，有问题不可怕，但要解决问题就要找到问题的根源，不能头痛医头，脚痛医脚，这只会徒增新的问题。

有时花了大力气处理的问题，结果却并不能令人满意，找到问题的根源是如此的困难，这本书的目的就是引导你去重新审视问题，找到问题的根源，从而解决问题。

以下是摘自书中的一个小故事：

有个新建的大楼，由于入住人员的增加，电梯不够用了。住户强烈不满，并要求房东解决此问题，若不解决就搬出去。这个情况下，房东能想到的方法：

１.给电梯提速

２.翻修通道，增加电梯

３.另外增加几部电梯

４.要求入住的公司修改作息时间，错开上下班高峰

５.限制大楼内人数

……

这些方法都有缺点，那该咋办呢？

后来，一个聪明的家伙意识到了问题的关键：其实就是你的期望和你的体验之间的差别。从这儿作为切入点，如果要解决电梯的问题，要么改变期望，要么改变体验。由于期望很难改变（每个人都希望电梯尽快到达），所以只好改变体验。

住户主要是嫌电梯太慢，于是就要想办法让乘电梯的人感觉电梯变快了。然后，这个家伙就想到了在电梯间设立几面镜子。出于虚荣心，人们总是会照照镜子打理下衣着发型，不知不觉就到了目的地。

这个故事想必大家都以各种形式听过，但都是或增加或减少了其内容，脱离了故事本身想要表达的内容，通过阅读原书，我想你会理解的更加清楚。

# 关于书名

书名“你的灯亮着么”是关于其中一个小故事的解决办法，当你读到那个小故事，就会明白。
